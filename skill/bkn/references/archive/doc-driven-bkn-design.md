## 五层架构定义

> **19 号方案**：以下「五层」仅为**文档阅读/组织顺序**（源文档按主题分层），**不是知识结构**——
> 22 号已废止「五层 + 四要素」表述，知识结构按要素 × 段形态 × 域（B 域/O 域/诊断域/结构域）组织。
> 诊断内容（L5 的「出错了怎么办」部分）现收拢在 `diagnostics/`（诊断路由层）。

| 层 | 名称 | 回答的问题 | 典型来源文档 |
|----|------|-----------|------------|
| L1 | product.bkn | 这是什么产品？为什么选它？ | 官网产品页、白皮书产品章 |
| L2 | architecture.bkn | 怎么实现的？技术原理？ | 白皮书原理章、实现原理汇总 |
| L3 | objects/scenario-*.bkn | 解决什么问题？怎么部署？ | 白皮书场景章、客户案例 |
| L4 | compatibility.bkn | 支持什么？有什么限制？ | 白皮书兼容性章、使用指引版本表 |
| L5 | objects/（DB 对象段）+ operations.bkn 相关锚点 | 怎么操作？出错了怎么办？ | 使用指引、配置手册、界面手册、安装手册 |

## 文档→BKN 映射规则

### 白皮书 (技术白皮书)
- 第1-3章 (挑战+传统方案+技术路线) → L1 product.bkn 产品定位
- 第4章 (技术原理+拓扑+部署) → L2 architecture.bkn
- 第5章 (兼容性) → L4 compatibility.bkn
- 第6章 (功能/性能特点) → L1+L2 分散
- 第7章 (应用场景+客户案例) → L3 objects/scenario-*.bkn

### 实现原理说明汇总
- 全量 → L2 architecture.bkn
- 每种DB的接口/日志/全量实现 → L2 原理矩阵
- 特殊模式 (如 MSSQL 三种模式) → L2 独立小节

### 软件使用指引
- 进程/服务介绍 → L5 topology.bkn
- 进程矩阵 → L5 topology.bkn
- 端口开放清单 → L5 env_matrix.bkn / L4 compatibility.bkn
- 硬件要求 → L4 compatibility.bkn
- 版本要求 → L4 compatibility.bkn (更精确)
- 目录结构 → L5 (故障排查参考)

### 配置手册
- 数据库连接配置 → L5 env_matrix.bkn
- 字符集配置 → L5 env_matrix.bkn
- 权限配置 → L5 env_matrix.bkn

### 界面操作手册
- 规则创建/修改/删除流程 → L5 actions/
- 数据比对/修复操作 → L5 actions/
- 监控/告警配置 → L5 actions/

## 交叉验证规则

当多份文档覆盖同一主题时:
1. 以**更精确**的为准 (如使用指引的版本 > 白皮书的版本)
2. 以**更新**的为准 (如 9.1.4 使用指引 > 旧版 Qdrant)
3. 白皮书给**原理和定位**，使用指引给**具体参数**
4. 冲突时标注差异，以实际操作手册为准
