# BKN 查询决策规则

> BKN 是查漏补缺的参考，不是每次操作的必选项。
> 本规则定义"查不查"的判断逻辑。

---

## 四象限判断法

```
                              需要BKN
                                 │
              ┌──────────────────┼──────────────────┐
              │                  │                  │
         遇到错误码         遇到不熟悉的        写操作(改/删/
         -4073等           数据库/术语         重启/停止)
              │                  │                  │
              ▼                  ▼                  ▼
         查知识型BKN         查知识型BKN        查操作型BKN
         diagnostics/       database.bkn       risks/constraints.bkn
         (诊断链路)          (源端要求)          (禁止项)
              │                  │                  │
              └──────────────────┼──────────────────┘
                                 │
─────────────────────────────────┼───────────────────────────────
                                 │
                              不查BKN
                                 │
              ┌──────────────────┼──────────────────┐
              │                  │                  │
         只读查询             熟悉操作             不确定但
        (list/query)        (重复执行过的)        Skill已覆盖
              │                  │                  │
              ▼                  ▼                  ▼
         直接执行             直接执行           直接执行
```

---

## 决策规则

```
查 BKN 的条件（满足任一即查）:
  □ 报错且有 error_code (-4073/-4016/-4071 等)
  □ 操作涉及不熟悉的数据库类型 (DM/OB/MSSQL三模式)
  □ 写操作 (create/start/stop/delete/restart)
  □ 操作失败重试前，不确定根因
  □ 用户问"怎么配"/"有什么区别"/"为什么不行"
  □ Skill SKILL.md 中没有覆盖到的信息

不查 BKN 的条件（全部满足才跳过）:
  □ 只读查询 (--list/--info/查看状态)
  □ 没报错 (正常操作流程中)
  □ Skill 内建信息已覆盖 (状态机/命令路径/基本约束)
  □ 之前成功执行过的同类操作，没变化
```

## 典型场景速查

| 用户输入 | 判断 | 结果 | 理由 |
|---------|------|------|------|
| "查规则列表" | 只读+skill有 | **不查** | skill 已覆盖 |
| "查 wx68-o-p 详情" | 报错-4073 | **查 risks.bkn** | 有 error_code |
| "重启 lym102-mysql" | 写操作 | **查 shared/risks.bkn** | 写操作 |
| "创建 Oracle→OB 规则" | 不熟悉OB | **查 database.bkn** | 不熟悉的DB |
| "Oracle到MySQL源端配什么" | 用户问怎么配 | **查 database.bkn** | 用户问怎么配 |
| "删除 lym-1" | MIGRATE状态 | **先不查** | skill 内建删除流程 |
| "lym102-mysql停了很久" | 只读查状态 | **不查** | 只读无报错 |
| "什么是流复制" | 查术语 | **查 term.md** | 术语不确定 |

## 查询工具选择

```
有关键词(错误码/DB名/术语) → search_files (1次, ~5行)
无关键词但知道文件     → read_file (1次, ~40行)
BKN有Qdrant引用       → Qdrant 检索 (1次, ~chunk)
以上都不够            → 组合: BKN骨架 + Qdrant原文

优先级: search_files > read_file > Qdrant > 不查
```

## 一句话

**报错必查，写入先查，不懂就查，熟悉跳过。**
