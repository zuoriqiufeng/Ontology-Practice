# 03 · `.bkn` 格式规范

> 唯一形式口径：本文件 ＋ `bkn/SCHEMA.md`（类型枚举）。机器可读常量在 `plugin/constants.py`，两者必须一致。

## 3.1 文件形态

- 纯 Markdown，UTF-8；文件名用 `snake_case`；一个文件可含多个段。
- 每个段以 `## <段类型>: <ID>` 起头（如 `## entity: syncrule`、`## relation: runs_on`）。
- 可选机器标注：`<!-- type: entity -->`，供解析器与 lint 使用。

## 3.2 frontmatter（对象文件必填）

```yaml
---
id: syncrule            # 规范 ID（与段头一致）
name: 同步规则           # 人类可读名
aliases: [规则, 任务]    # 同址别名：与基点同文件，保证一起被召回
---
```

别名纪律：**别名写在基点所在文件**，不建中央表。

## 3.3 载荷三态

| 形态 | 用途 | 约束 |
|---|---|---|
| **表格** | 结构化事实（枚举、矩阵、阈值对照） | 表头带单位；一行一实例 |
| **KV** | 定义性单值（标识、类型、模式） | 键名稳定；不写命令 |
| **散文** | 原理与判据 | 不承载可执行内容 |

## 3.4 硬规则

1. **不写命令 / 参数值 / 路径**：写成 `skill:<名>` 指针。
2. **不写错误码**：码只作入口（Q27），码表在 Tool 层侧车。
3. **不写数值阈值**：阈值属值数据，由 Skill 或侧车提供。
4. **表格必须有表头且列数一致**；空表要写「（无）」。
5. **交叉引用用纯文本路径**（`bkn/SCHEMA.md`），不写 Markdown 链接。

## 3.5 反模式（出现即改）

| 反模式 | 症状 | 正解 |
|---|---|---|
| 复制粘贴同一张表 | 两处结论会漂移 | 一处定义，另一处写指针 |
| 用标签页/HTML 排版 | 解析器读不出 | 用表格或 KV |
| 在 `risk` 段写处置步骤 | 越界到 Skill | 只写风险与判据，处置留 Skill |
| 用 ID 编码角色（`dbnode:source`） | 语义塞进名字 | 角色写成边类型 |
