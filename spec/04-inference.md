# 04 · 推理语义

> 唯一真值：`plugin/edge_semantics.yaml`（可穿边集、深度/条数上限、停止前缀）。本文件是它的**人读说明**，不另立口径。

## 4.1 一条边的语义

每个关系类型声明：方向是否有意义（`reverse_ok`）、是否可传递（`transitive`）、复合规则（`compositions`）、是否对称（`symmetric`）、端点命名空间。

## 4.2 遍历边界（walk policy）

| 项 | 约定 |
|---|---|
| 可穿边集 | 白名单（约 25 种）；不在白名单的边**不穿** |
| 深度 / 路径数 | `max_depth=5`、`max_paths=12`（默认） |
| 停止前缀 | 到达 `skill:` / `log:` / `dimension:` / `mechanism:` 即停 |
| 每跳依据 | 必带 `from / edge / to`，可选 `way`（复合腿说明） |

## 4.3 四类展开

1. **反查**（`direction=in`）：谁引用了我；
2. **复合**（`compositions`）：两跳合成一条语义（如「登记后运行在」）；
3. **闭包**（`closure`）：传递/对称关系的只读闭包；
4. **影响面**（`impact`）：沿已声明的承载边展开受牵连单元。

## 4.4 能推 / 推不出

| 能推 | 依据 |
|---|---|
| 结构可达、依赖链、受影响单元、维度 → Skill / 日志的落点 | 边 |
|
| **推不出** | 原因 |
|---|---|
| 因果链与根因定论 | 机制间因果边需真实案例证据 |
| 现场实例事实（某台机器此刻状态） | 本仓是 TBox，无 ABox 源 |
| 数值阈值是否超标 | 阈值属值数据，不在本体 |
| 条件归类（互斥/蕴含） | 需要一致性推理机，当前只有形状检查 |

## 4.5 能力坐标

`L0` 检索 → `L1` 结构化查询 → `L2` 图遍历/闭包/影响面 → `L3` 条件归类 → `L4` 因果/机制。
当前实现：**L2 到位**、`L4` 半落地（候选机制 + 证据缺口，不给根因定论）。
