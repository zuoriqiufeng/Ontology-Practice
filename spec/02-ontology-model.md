# 02 · 本体模型（四元终态）

## 2.1 段类型：只有四种

| 段类型 | 语义 | 对应 KWeaver 四元 |
|---|---|---|
| `entity` | 世界里有什么：类定义 + 实例登记 | Object |
| `relation` | 谁和谁相连（有类型、有方向、有依据） | Relation |
| `action` | 能做什么（能力声明，不含执行） | Action |
| `risk` | 会出什么问题（症状/风险，不含处置） | Risk |

历史类型（`index` / `matrix` / `symptom` / `class` / `scenario` 等）均已退场；**方案类对象**用 `entity` 定义。

## 2.2 目录：4 类 + 模板

```
bkn/
├── objects/     # 业务对象、进程对象、主机、维度类集、DB 对象
├── actions/     # 能力/动作声明
├── risks/       # 风险与症状
├── relations/   # 关系段（含拓扑、机制因果）
└── templates/   # 生成模板（不参与推理，只供复用）
```

## 2.3 命名空间（谁承载「有哪些」）

| 前缀 | 承载 | 权威落点 |
|---|---|---|
| `object:` / 裸名 | 业务对象类与实例 | `objects/*.bkn` |
| `process:` | 运行时进程 | `objects/*.bkn` + 拓扑边 |
| `dimension:` | 检查维度（有界集） | `objects/dimensions.bkn` |
| `symptom:` | 症状（有界集） | `risks/*.bkn` |
| `error:` / 码 | **不进本体**：码只作入口 | Tool 层侧车（码表/语义规则） |
| `log:` | 日志源 | 进程对象属性 + 检索源 |
| `mechanism:` | 机制（因果候选） | `relations/mechanism_causality.bkn` |
| `skill:` | 值委托/能力指针 | 由各产品 Skill 提供 |

## 2.4 TBox 与 ABox

- 本仓是 **TBox（类级 / 产品级）**：可以推「什么和什么有关、什么约束什么」。
- **ABox（现场实例事实）** 需要外部实例源；没有源就不猜，返回「需要实例数据」。

## 2.5 两条形式纪律

1. **零冗余**：同一条结论只允许一个落点（一个表、一条边或一个字段）。
2. **零元信息**：不进本体的东西（编码、行号、渲染指令、命令）一律不写。
